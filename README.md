# football-on
FOOTBALL ON (em desenvolvimento): aplicação web de futebol, leve e rápida, pensada para telemóveis e redes lentas. Resultados, jogos por continente, cartazes de próximos jogos, modo Economizador de MB e instalação como app (PWA). Consulta sem registo obrigatório. Dados reais via APIs, em integração.
